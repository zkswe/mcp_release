## 更新开机LOGO

- 首先准备一张开机LOGO图片，图片必须满足以下条件：
  - 图片名称固定为 boot_logo.JPG，文件后缀是大写的JPG
  - 图片分辨率必须与屏幕分辨率完全相同
  - 图片不宜过大，最好保持在100KB以内
  - 开机LOGO图片应尽量简单，推荐以纯色为背景，再加上简单的图标或文字
- 将 boot_logo.JPG 拷贝到TF卡根目录下
- 将TF卡插入到机器中，设备会自动弹出升级提示。选择boot_logo然后点击升级即可。
- 升级完成后系统会关机重启。此时拔出TF卡。

## 更加丰富的"开机LOGO"

- 用一张纯黑色的图片升级为开机LOGO。
- 应用程序的第一个界面视为你的"开机LOGO"。
- 应用程序的第一个界面尽量不要有耗时操作。

## 延长开机LOGO的显示时间

```c++
#include <unistd.h>

static void onUI_init() {
 //延迟5秒
 usleep(1000 * 5000);
}
```
