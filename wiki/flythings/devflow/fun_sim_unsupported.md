# 模拟器功能禁止使用

> ⚠️ 2026-09-01 需求方确认：**开放版 MCP 不支持模拟器功能**。

- **`fun sim` 命令禁止采用**：当前版本未开放，暂不支持
- **QEMU 模拟器也不是对外能力**：仅是内部开发/自测用的本地方案，开放版 MCP 不提供
- 不要向客户承诺/演示模拟器方案

## 可用的运行/交付方式（替代模拟器）
- **真机运行**：`fun build` 编译 → `fun launch` 或 adb push 到设备运行
- 交付/验证一律走真机，模拟器功能开放版不支持
