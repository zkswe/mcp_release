title: 4G

## 引入头文件

```c++
#include <net/NetManager.h>
#include <net/LTE4GManager.h>
```

## 打开系统内置的4G设置界面

```c++
EASYUICONTEXT->openActivity("LTE4GSettingActivity");
```

## 获取4GManager对象

```c++
LTE4GManager* manager = NETMANAGER->getLTE4GManager();
#define LTE4GMANAGER NETMANAGER->getLTE4GManager()
```

## 检测是否支持4G

```c++
LTE4GMANAGER->isSupported();
```

## 获取4G电源状态

```c++
LTE4GMANAGER->getPowerState();
```

## 开关4G

```c++
LTE4GMANAGER->setPower(true); //开4G
LTE4GMANAGER->setPower(false);//关闭4G
```

更多操作，可查看头文件。
