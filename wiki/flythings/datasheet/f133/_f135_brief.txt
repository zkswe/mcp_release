Cost-Effective Decoding  Platform
The F135 is an advanced application processor designed specifically for the video decoding market. It has a rich set
of peripheral interfaces and many new features to provide a low-cost solution design.
Integrated 64-bit RISC CPU processor provides powerful computing performance.
Supports external DDR2/DDR3/DDR3L, maximum capability up to 256 MB.
Supports H.265/H.264 1080p@60fps video decoding, and MJPEG/JPEG 1080p@60fps video encoding.
Rich peripheral interfaces, such as USB, SDIO, UART, SPI, PWM, GPADC, GPIO_ADC, IR, and so on.
Rich video interfaces, RGB888, Dual-LVDS, MIPI-DSI for Display.
