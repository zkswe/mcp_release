## 1. 协议口径（来源工程实测，不是本仓推断）

| 项 | 值 | 备注 |
|---|---|---|
| 设备发现 | UDP 广播 `255.255.255.255:8899`，每 ≈2 s，正文 `zkswe:<设备名>`（UTF-8，**无换行**；名字空则 `Frame`） | 9/24 版加了 `zkswe:` 前缀；6 月版只广播名字 |
| 传输 | TCP `0.0.0.0:9000`；accept 后的连接 socket **收发阻塞超时 2 s** | 不是整个文件的限时；等待下一包头期间长时间无数据才会触发 |
| 公共包头 | `type`(uint8) + `len`(uint32 **大端**)，`len` = 文件内容字节数，有效 `1..500 MiB` | 非法类型/长度 → 直接关连接，**不返回结构化错误** |
| 类型 | `1`=图片 / `2`=视频 / `3`=扩展（保留分支）；`0`=文本兼容分支 | 文本分支：包头后直接读 `len` 字节文本 → 回 `OK\n`（无文件名、无分块 ACK） |
| 文件包 | `type(1B) + fileLen(4B BE) + nameLen(2B BE) + filename(UTF-8) + fileData` | 文件名 UTF-8 长度 `1..256` 字节；禁 `..` `/` `\` |
| 分块 | `32 KiB`；**非末块**回 `ACK <累计字节>\n`，**末块**校验改名后回 `OK\n` | ACK 数字是**当前文件累计内容字节**（不含包头/文件名），每文件从 0 重新累计 |
| 落盘 | 先写 `<name>.tmp` → 校验大小 == `fileLen` → `rename` → 回 `OK\n`；失败不改名 | 残留 `.tmp` 由后续清理流程删除 |
| 接收目录 | `/mnt/extsd/mp_transfer/`（原工程 `config.h` 的 `MP_PATH`） | 移植换自己目录，**末尾带 `/`** |

⚠️ 一条连接可连续收多个文件（回 `OK` 后继续读下一包头）；**客户端必须持续读 ACK**，
否则服务端发送缓冲填满 → 2 s 超时断连（来源工程明确记录）。

## 2. 前置条件（移植到新平台/新工程）

1. **可写目录**：`MP_PATH` 指向设备可写分区（默认 `/mnt/extsd/mp_transfer/`，末尾带 `/`）；
   没有外置卡的板子要换路径（例如 `/data/...`）并**实测存在与可写**。
2. **`base::Task` 底座**：`tcp_receive.h` / `broadcast_task.h` 继承 `base::Task<P>`，用到 `DECLARE_SINGLETON_PATTERN` /
   `DISALLOW_COPY_AND_ASSIGN_METHOD` → 目标工程要有 `base-utility`（或按 README 换项目自己的后台线程）。
3. **日志 / RAII**：源码里用了 `LOGD/LOGE` 与 defer 之类 → 换成项目自己的（README「怎么用」第 2 条）。
4. **局域网条件**：手机与设备**同一局域网**，且路由器**未开 AP 隔离/客户端隔离**（否则 UDP 广播到不了小程序）。
5. **可信网络**：无认证、无加密、无 CRC、无断点续传、无协议版本协商 → **仅适合可信局域网**。

## 3. 怎么验收（本模块的三层验收口径）

| 层 | 做法 | 期望 |
|---|---|---|
| ① PC 侧（不接设备） | `py ./src/python/receiver.py --name PythonFrame --output ./received`（纯标准库，Python ≥3.9；多网卡/VPN 加 `--bind/--broadcast --verbose`） | 手机小程序能发现该"设备"并传图；收到的文件完整（长度一致），逐块 ACK/末块 `OK` 正常 |
| ② 设备侧（不上屏） | 把 `example/mp_transfer_min_example.cc` 的接线抄进工程 → `fun build` → 推设备跑 | logcat 看到广播任务启动 + 监听 9000；小程序能发现设备名 |
| ③ 端到端 | 小程序传图片/视频 → 设备落盘 | 文件出现在 `MP_PATH`，大小 == 协议声明 `fileLen`，无残留 `.tmp` |

⚠️ 本仓**没有** ①②③ 的设备侧记录（见 §0），所以上表第 ②/③ 层是「怎么验」而不是「已验结果」。

## 4. 已知边界（写需求时先看）

- 无版本协商 / 无设备唯一 ID（端口固定 9000）/ 无认证加密 / 无 CRC 校验 / 无断点续传；
- 非法请求**直接断连不报错**（客户端拿不到结构化错误码）；
- TCP 空闲超时短（2 s）→ **不适合保活**，只能"来一个文件传一个文件"；
- 文件名非法（含 `..` `/` `\`、长度越界）会被拒绝 → 客户端要先自检；
- 单个文件最大 `500 MiB`；分块固定 32 KiB（改分块必须两端一起改）。
