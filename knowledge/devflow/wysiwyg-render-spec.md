# 渲染语义规格（离线「所见即所得」单点真相）

> 检索导引：问「离线渲染和真机差多少 / 为什么要上机才能看效果 / 文字位置不对 / alignment 取值 / 绘制顺序 / 图比控件大怎么办 / 预览和真机不一致」→ 本文。
> **本文是渲染/布局语义的唯一真相**；散在各处的口径（`json-layer-rules`、`text-box-height-rule`、`ui-asset-rules`、`scrollwindow-layout-checklist`、`ui-layout-verify`、`controls.md`）只保留各自专题，语义冲突以本文为准。

## 0. 一句话

**控件 = 矩形 + 背景图或纯色 + 文字 + 子控件；绘制顺序 = json 树序；图按矩形拉伸填充；文字用设备同款字体按对齐位模型摆放。** 静态界面离线渲染可做到与真机**几何/颜色/图层 100% 一致**，仅文字字形边缘存在 ±2px 的栅格化差异（设备自带 FreeType vs 离线渲染器，肉眼不可分）。

## 1. 边界（先划清：什么做不到，别承诺）

| 类别 | 离线可做 | 说明 |
|---|---|---|
| 静态界面（矩形/图/纯色/文字/层级/裁剪） | ✅ 100%（±字形栅格化） | 本文 §2–§5 |
| 运行期数据文本 | ❌ 不比对 | 值/状态由代码灌（如 `已连接 - <本机IP>`、`2/2`）→ 比对时必须**排除**这些控件的盒 |
| 滚动位置 / 拖拽手感 / 回弹 | ❌ 需上机 | 静止态按 json 坐标画（内层 window 的负 left/top = 初始偏移） |
| 动画 / 帧序列 / 视频层 / 屏保息屏 | ❌ 需上机 | 属引擎运行期行为 |
| 屏幕旋转 / 倒装 / 系统栏 | ❌ 需上机 | 属系统层配置（见 `package-properties-easyui-cfg`） |

## 2. 绘制规则（逐条给依据）

| # | 规则 | 依据 / 状态 |
|---|---|---|
| R1 | **绘制顺序 = json 树序**：父先子后；同层按出现顺序，**后定义的画在上面** | 引擎行为；渲染器按 dict 写入顺序遍历（json 保序） |
| R2 | 单节点顺序严格：**底色 → 背景图 → 文字 → 递归子控件** | 「箭头被文字盖住」实测解释（引擎先画背景图后画文字） |
| R3 | **图 != 矩形 → 拉伸填充**（stretch-to-fill），不是原样贴、不是居中裁剪 | 钟工 2026-10-01 口径 + 官方 `SampleUI-New` `navi/fh.png` 44×26 放进 72×40 按钮 |
| R4 | 颜色：`-1` = 不填充（透明）；`0` = 不透明黑；其它 `0xRRGGBB`。有 `backgroundPic` 时先铺底色再贴图（贴图透明区露底色） | 引擎字段语义；`window` 用 `backgroundColor`，文本/按钮用 `bgColorTab.color0` |
| R5 | 子控件坐标**相对父矩形左上角**，无 flex / 无层叠 / 无继承 | 绝对布局模型 |
| R6 | 滚动容器（`scrollwindow`/`pagewindow`/`slidewindow`）按自身 rect **裁剪**子内容 | 引擎视口语义 |
| R7 | 文字：`fontSize`(px) + `colorTab.color0` + `bold`/`italic` + `\n` 多行（行距 `rowSpace`） | 见 `text-box-height-rule`（盒高/字号下限） |
| R8 | **字体必须与设备同款 TTF**（按工程 `EasyUI.cfg` 的 `font` 顺序取第一个存在的），否则字宽/换行/截断全对不上 | `.71` 设备 `/res/font/HanSans-Medium.ttf` 与工程 `font/HanSans-Medium.ttf` 字节级一致（1,763,788 B） |
| R9 | 图/文字贴矩形时**不做抗锯齿重采样假设**：普通 PNG 拉伸用最近邻；`.9.png` 走九宫格 | R3 + `nine-patch-rule` |
| R10 | 控件专有绘制（各自独立）：qrcode 模块、seekbar 进度+thumb、circlebar 弧、imageanim 首帧、listview 行、edittext 文本/hint | 见各控件字段文档 |

## 3. 相关实现（本仓）

- **渲染器**：`ui_tools/json2img.py` —— `json → PNG`（引擎等价；`--scale` 放大一律 NEAREST；`--report` 打印**未支持/降级清单**，不静默跳过）
- **一致性校验**：`ui_tools/wysiwyg_diff.py` —— 渲染图 vs 真机截图 → 超容差像素占比 + **逐控件归因** + 自动排除运行期文字盒
- 用法：
  ```bash
  python tools/ui_tools/json2img.py <项目根> --page wall --out wall.png --scale 2 --report
  python tools/ui_tools/wysiwyg_diff.py wall.png <真机截图.png> <项目根>/ui/wall.json --tol 2
  ```

## 4. 对齐位模型（2026-10-01 真机定案；旧口径只记了 36/37/38）

`alignment` 是**位模型**：`h = a & 3`（0 左 / 1 中 / 2 右）、`v = (a >> 2) & 3`（0 顶 / 1 中 / 2 底），高位的 32/8 是引擎附加标志，不影响对齐。

| 实测值（真机验证） | 语义 | 工程里等价写法 |
|---|---|---|
| `36` | 靠左 + **垂直居中** | `4`（同语义，工程里大量在用） |
| `37` | 水平居中 + 垂直居中 | `5` |
| `38` | 靠右 + 垂直居中 | `6` |
| `33` | 顶部对齐 | `1` |
| `41` | 底部对齐 | `9` |

**为什么必须记全**：工程里 **91% 的文字控件用 `4/5/6/0/1`**；只按「36 = 左」处理会把右对齐的值（如多屏拼接页「返回 ＞」`alignment=6`）摆到左边。
**真机基线二选一证据**（`projects/SmartPanel_HA`，480×480，基线与渲染均存档于 `docs/evidence/scrollwindow-20261001/`）：

| 页 | 全部按 36（左对齐） | 按位模型 |
|---|---|---|
| 多屏拼接页 | 32 区域 / **8608 px** | 10 区域 / **1690 px** ← 好 5.1× |
| 设置页顶部 | 28 区域 / 4778 px | 27 区域 / **3456 px** |

## 5. 验收口径（离线「所见即所得」怎么算过）

1. **静态一致率**：排除运行期文字盒后，`超容差像素 / 总像素` ≤ **1.5%** 且差异必须落在文字 ink 边缘 2px 带内；
2. **几何零漂移**：不允许整块位移 / 缺失 / 圆角变形（diff 清单里出现 ≥4px 连通块即 FAIL）；
3. **首例实测（2026-10-01）**：多屏拼接页静态 **97.36%**、设置页顶部 **95.32%**（残差 100% 为字形边缘抗锯齿，逐控件归因 + 视觉复核双证）；
4. 运行期文字区单独统计、不计入判据（多屏拼接页 25.6% / 设置页 12.5% 的差异全部来自设备 live 值）。
