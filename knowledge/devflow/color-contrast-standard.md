# 配色对比度标准（字色 / 底色 / 底图）

> 检索引导：字看不清 / 灰底白字 / 副文本太暗 / 深色界面文字档 / 对比度不够 / WCAG / 4.5:1 /
> 暗灰压深底 / `#5F5F68` 能用吗 / 深底副文本用什么色 / 改完怎么核 / 老工程要不要回头改 → 本文。
> 机器判定唯一入口 = `check_all` **第 34 项文本对比度**（复用 `tools/qa/contrast_check.py`）。

## 1. 阈值（选一条写死，别在边缘试探）

| 类别 | 阈值（WCAG 2.1 AA） | 本项目口径 |
|---|---|---|
| 正文 / 标签 / 按钮文字（`fontSize < 24`） | ≥ **4.5:1**| 平台字号下限 18px 且非粗体 → **一律按 4.5**|
| 大字（`fontSize ≥ 24`，或 ≥18.66px 且粗体） | ≥ 3:1 | 很少用 → 默认不启用 |
| 非文本图形（图标/描边/分隔线/状态指示） | ≥ 3:1 | 图标/描边按 3:1 |
| 禁用 / 不可操作控件 | **豁免**| 但仍必须有不靠颜色的线索（灰化 + 不响应） |

- 设备字库是裁剪字库、渲染无次像素 ⇒ **不要在 4.5 边缘试探**，留到 5.0 以上余量（同色值在真机比 PC 预览更糊）。
- 分级：页面/容器**可信底**（平色或近纯色图 σ≤6）不足 → `FAIL`；**照片/渐变底**（σ>6）与控件自述底只 `NOTE`；临界带（≥0.9×阈值）降级 `NOTE`。

## 2. 深底（深色主题）文字档 —— 2026-10-01 定版

三类深底：页底 `#17171B` / 卡片底 `card.9.png` ≈ `#27272F` / 芯片底 `sschip141x40.png` ≈ `#23242E`。

| 用途 | 色值 | 对 `#17171B` | 对 `#27272F` | 对 `#23242E` |
|---|---|---|---|---|
| 主文字 / 标题 | `#ECECF0` | 15.17x | 12.57x | 13.07x |
| **副文本 / 说明行 / 英文小标题**| **`#9A9AA2`**| **6.40x**| **5.30x**| **5.51x**|
| 禁用 / 不可操作 | 灰化 + 不响应 | 豁免 | — | — |

**禁用**：`#5F5F68` 这类中灰压深底（对 `#17171B` = **2.83x**、卡片底 2.34x、芯片底 2.44x）不达标 —— 旧工程遗留，**新工程不写**。
`#9A9AA2` 是工程里既有的亮副文本档（原 `ui/*.json` 已有 64 处），标准做法是把**暗副文本色并入它**，不是新造色。

## 3. 浅底（浅色主题）文字档（速查）

| 用途 | 色值 | 白底 | `#F3F3F3` 底 |
|---|---|---|---|
| 主文字 | `#010101` | 18.9x | 17.0x |
| 次要文字 | `#666666` | 5.74x | 5.17x |
| 三级 / 说明小字 | `#6E6E6E` | 5.10x | 4.60x |
| 主题文字（蓝） | `#0052D9` | 6.54x | — |

- **浅底禁白字**（`#E7E7E7`/`#F3F3F3` 上白字仅 1.1~1.2x）。
- **主题色当文字必须降档**：`#2BA471` → `#006C45`、`#E37318` → `#954500`、`#D54941` → `#AD352F`（蓝例外，`#0052D9` 可同时作文字）。

## 4. 硬规则

1. 文字色**跟底走**，不跟组件名走：换底图/换变体时字色必须一起换（运行时 `setTextColor` 联动）。
2. 半透明底按**合成后的颜色**算对比度（α<255 必须合成到父底色再判）。
3. **同一界面同义色只允许一套**（次要文字不要出现两个近似灰）。
4. 深底副文本一律 `#9A9AA2`、主文字 `#ECECF0`；层级用「字号 + 两档灰」，不靠更多灰阶。
5. 改色 / 改图后必跑 `check_all`：新增 `FAIL` 必须为 0，否则写进例外登记并说明理由。
6. **老工程不回头改**：改色牵动出图与真机像素基线，标准只对**新工程**生效（已交付工程按原样保留）。

## 5. 工具

```bash
python ui_tools/check_all.py <项目根>        # 全检（第 34 项即本文判据）
python tools/qa/contrast_check.py <项目根> --all --json temp/cc.json   # 单跑字底对比度
```

输出三类：`FAIL` = 真不达标要改；`exempt` = 禁用态等豁免；`suspect` = 底没解析到（弹层/遮罩内）→ 以真机帧为准。
